# Restoring Secret of Hegra

- **Repository:** https://github.com/lolo67fa/SecretOfHegra (private)
- **Branch:** `main`
- **Unity:** 6000.6.3f1 (revision 45d8eee7de74), installed with **Android Build Support** (OpenJDK + Android SDK & NDK)
- **Main scene:** `Assets/SecretOfHegra/Scenes/SecretOfHegra.unity` (the only scene in Build Settings)
- **Playable build:** GitHub Release `v0.1.0` → `SecretOfHegra.apk` (Meta Quest 3 / 3S)

## Steps

1. `git clone https://github.com/lolo67fa/SecretOfHegra.git` (no Git LFS, no submodules).
2. In Unity Hub: **Add ▸ Add project from disk** and choose the clone. Open it with 6000.6.3f1.
3. Packages restore automatically from `Packages/manifest.json` + `packages-lock.json`. They all come from the public Unity registry or are built in. The first open re-imports everything and rebuilds `Library/`.
4. Open the main scene. If anything looks broken, run **Tools ▸ Secret of Hegra ▸ Build or Repair Game** (the scene is generated by `Assets/SecretOfHegra/Scripts/Editor/HegraBuilder*.cs`).
5. Build the APK: **Tools ▸ Secret of Hegra ▸ Build Release APK (Quest)** (output: `Builds/Quest/`).

## Signing

The APK in Release `v0.1.0` is signed with the Android **debug** key (`%USERPROFILE%\.android\debug.keystore`, SHA-256 `74:88:AB:D2:…:EF:6F`). It is deliberately not in Git. Keep a private copy of that file so that new builds can be installed over the existing install on the headset. A custom release key can be supplied at build time with the `HEGRA_KEYSTORE`, `HEGRA_KEYSTORE_PASS` and `HEGRA_KEY_ALIAS` environment variables.

## Not in the repository (regenerated or local only)

`Library/`, `Temp/`, `Logs/`, `UserSettings/`, `obj/`, `*.csproj`/`*.slnx`, `Builds/` (APKs live in GitHub Releases), `Backups_SecretOfHegra/` (old local snapshots), `.utmp/`.
