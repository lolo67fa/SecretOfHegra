Modification (2026-10-05, for the game "Secret of Hegra"): the Nabataean letters
U+10880–U+108AF are additionally mapped to Private Use Area code points
U+E880–U+E8AF, because TextMesh Pro's dynamic atlas in this Unity version did not
add glyphs from the supplementary plane. Outlines are unchanged. The family was
renamed to "Hegra Nabataean PUA". The modified font remains under the OFL 1.1.
